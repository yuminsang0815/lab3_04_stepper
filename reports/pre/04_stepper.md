# 실험 전 레포트: 스텝모터 위상 제어

작성일 2026-09-25.

## 1. 동작 원리와 핵심 파라미터 계산

### 동작 원리
온보드 50 MHz 메인 클록을 분주하여 생성한 clock-enable 타이밍마다 4상 스텝모터의 여자 코일 구동 신호(`stepmotor[3:0]`)를 순차 전이시킨다. 모터 제어 방식으로는 토크가 강하고 위치 제어가 안정적인 2상 여자(2-phase excitation, 4-step sequence) 방식을 적용한다. 2비트 상태 레지스터(`state`)를 기반으로 정방향(CW, `direction=0`)에서는 상태가 `0 -> 1 -> 2 -> 3 -> 0`으로 순차 증가하고, 역방향(CCW, `direction=1`)에서는 `0 -> 3 -> 2 -> 1 -> 0`으로 역순 전이한다. `enable=0`일 때는 카운터가 0으로 초기화되면서 상태 전이가 정지되고, 마지막 여자 패턴을 그대로 유지하여 모터의 회전자 위치를 고정하는 홀딩 토크(Holding Torque)를 발생시킨다. 외부 비동기 제어 신호인 `enable`과 `direction`에는 2단 플립플롭 동기화기(`ASYNC_REG`)를 배치하여 메타스테이블(Metastability)을 방지한다.

### 4상 2상 여자 시퀀스 매핑
| State (2진) | 코일 패턴 stepmotor[3:0] | 활성화 코일 | 동작 설명 |
|:---:|:---:|:---:|---|
| 2'd0 (00) | 4'b0011 | 코일 A, B (bit 0, 1) | 초기 및 기준 여자 위상 |
| 2'd1 (01) | 4'b0110 | 코일 B, C (bit 1, 2) | CW 회전 시 2단계 위상 |
| 2'd2 (10) | 4'b1100 | 코일 C, D (bit 2, 3) | CW 회전 시 3단계 위상 |
| 2'd3 (11) | 4'b1001 | 코일 D, A (bit 3, 0) | CW 회전 시 4단계 위상 |

### 핵심 파라미터 계산
1. **실제 보드 구동 파라미터 (`STEP_CYCLES`)**:
   - 입력 주 클록 주파수 $f_{\mathrm{clk}} = 50\text{ MHz} = 50,000,000\text{ Hz}$
   - 모터 스텝 주파수 $f_{\mathrm{step}} = 100\text{ Hz}$ (초당 100회 스텝 이동)
   - 1스텝당 필요한 클록 주기 수:
     $$\text{STEP\_CYCLES} = \frac{f_{\mathrm{clk}}}{f_{\mathrm{step}}} = \frac{50,000,000}{100} = 500,000\text{ cycles}$$
   - 분주 카운터 비트 폭:
     $$\text{COUNT\_WIDTH} = \lceil\log_2(500,000)\rceil = 19\text{ bits}$$
($2^{18} = 262,144 < 500,000 \le 2^{19} = 524,288$)

2. **시뮬레이션 가속 축소 파라미터**:
   - 빠른 기능 검증을 위해 `CLK_HZ = 8`, `STEP_HZ = 2`로 축소 설정한다.
   - 축소된 스텝 주기 수:
     $$\text{STEP\_CYCLES}_{\mathrm{sim}} = \frac{8}{2} = 4\text{ cycles}$$
   - 시뮬레이션 환경에서는 정확히 4클록마다 1스텝씩 상태 전이가 발생한다.

## 4. 시뮬레이션 결과 및 수정 실험

### 정상 시뮬레이션 확인
- **[종료 로그](../../evidence/04/vscode/simulation.txt)**: `LAB3_STEPPER_PASS checks=8`, 종료 시각 `831000 ps (831 ns)`
- **[파형 분석](../../evidence/04/vscode/wave.png)**:
  - `enable_sync=1`, `direction_sync=0`인 구간에서는 매 4클록마다 `state`가 `0 -> 1 -> 2 -> 3 -> 0`으로 증가하며, 이에 맞추어 `stepmotor` 출력이 `0011 -> 0110 -> 1100 -> 1001 -> 0011`로 순환한다.
  - `direction_sync=1` 인가 시 다음 유효 스텝에서 `state`가 `3 -> 2`로 역순 감소하며 출력이 `1001 -> 1100`으로 올바르게 역전된다.
  - `enable_sync=0`으로 전환된 이후에는 12클록 동안 클록이 계속 인가되어도 `count=0`으로 유지되고 `state=2`, `stepmotor=4'b1100` 상태가 변함없이 안정적으로 유지된다.

### 수정 실험 (오류 주입 및 복구)
`STEP_HZ` 파라미터를 2에서 1로 절반 감속 수정하여 스텝 간격 클록 수가 늘어났을 때 테스트벤치가 타이밍 오류를 검출하는지 점검한다.

| 실험 단계 | 설정 내용 | 기대 동작 | 실제 실행 결과 | 비고 |
|---|---|---|---|---|
| 정상 실행 | `CLK_HZ=8, STEP_HZ=2` | 스텝 간격 4클록 (`STEP_CYCLES=4`) | `LAB3_STEPPER_PASS checks=8` (831 ns 종료) | 정상 통과 |
| 고장 주입 | `STEP_HZ=1` 로 변경 | 스텝 간격이 8클록으로 지연되어 전이 | 상태 전이 타이밍 불일치 또는 `#5000 timeout` 발생으로 중단 | 테스트벤치 검출 확인 |
| 원복 복구 | `STEP_HZ=2` 복원 | 스텝 간격 4클록 복원 | `LAB3_STEPPER_PASS checks=8` 복구 | 정상 확인 |

## 5. 보드 실험 계획 및 관찰 항목

### 하드웨어 환경 및 핀 매핑
- **타깃 FPGA**: Spartan-7 `xc7s75fgga484-1`
- **클록 및 리셋**: 온보드 50 MHz 클록 발진기 (B6 핀), 리셋 푸시버튼 K4
- **입력 스위치/버튼**: enable 버튼/스위치 N8, direction 버튼/스위치 N4
- **스텝모터 출력 핀**: Y20(코어 bit 3), Y22(bit 2), AA20(bit 1), AA21(bit 0)

### 보드 관찰 절차
1. 보드 전원을 인가하기 전, 외부 스텝모터 드라이버 모듈(ULN2003 등)의 코일 입력 4핀과 공통 GND 결선이 올바른지 확인한다.
2. 비트스트림(`lab3_stepper.bit`)을 다운로드하고 K4 버튼으로 리셋 초기화를 수행하여 모터가 정지 상태(`stepmotor=0011`)를 갖는지 확인한다.
3. N8(enable)을 활성화하고 N4(direction=0)를 인가하여 스텝모터 축이 시계 방향(CW)으로 100 Hz 스텝 속도에 맞추어 부드럽게 정속 회전하는지 관찰한다.
4. N4(direction=1)로 변경하여 회전 방향이 즉시 반시계 방향(CCW)으로 역전되는지 확인한다.
5. N8(enable=0)을 비활성화하여 모터 회전이 즉시 멈추고, 회전자 축을 손으로 비틀었을 때 홀딩 토크에 의해 고정되어 쉽게 돌아가지 않는지 확인한 뒤 사진 및 영상으로 기록한다.
